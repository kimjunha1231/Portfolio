## 원천 키와 기준 ID를 연결하는 row map

Scene: 밝은 기술 설명 인포그래픽. 왼쪽에는 원천 한 행 카드와 source type·source record key를 보여주고, 가운데에는 크게 강조한 INVENTORY_SOURCE_ROW_MAP 카드가 있습니다. 가운데 카드 안에는 원천 키, 기준 ID, 매핑 상태, 매핑 버전의 네 영역을 짧은 아이콘과 함께 배치합니다. 오른쪽에는 상품·SKU, LOT·가격, 재고·정책이라는 세 개의 canonical 대상 카드가 세로로 정렬됩니다. 원천 한 행에서 row map을 거쳐 정확한 대상 행으로 이어지는 화살표만 표시하고, 매핑되지 않은 행은 별도의 작은 보류 점선 영역으로 표현합니다.
