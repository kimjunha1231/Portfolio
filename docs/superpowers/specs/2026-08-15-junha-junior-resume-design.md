# 김준하 신입 개발자 이력서 2페이지 디자인

## 목적

기존 3페이지 이미지형 이력서와 포트폴리오의 공개 정보를 바탕으로, 신입 개발자 채용 담당자가 짧은 시간에 역할·기술·성과를 파악할 수 있는 2페이지 이력서를 만든다.

## 콘텐츠 원칙

- 확인 가능한 사실만 사용한다: 숭실대학교 컴퓨터학부, 2026년 8월 졸업예정, 연락처, GitHub, 공개 프로젝트와 수상 내역.
- 자기소개는 프론트엔드 중심 풀스택 개발 방향과 성능·상태 관리·사용자 경험 개선 관심을 한 문단으로 요약한다.
- 프로젝트는 프로젝트명, 기간, 역할, 핵심 기여, 측정 가능한 결과 순서로 2~4줄씩 정리한다.
- 주요 프로젝트는 JobSecretary와 Dearfam으로 두고, TITO와 POPPET은 짧은 사례로 배치한다.

## 레이아웃

- A4 세로 2장, 여백과 파란 포인트 컬러는 기존 위니브 템플릿의 시각 언어를 유지한다.
- 1페이지: 프로필 헤더, 기술 스택, 핵심 역량, 활동·수상 요약.
- 2페이지: 프로젝트 4개. 각 프로젝트는 `문제/역할 -> 구현 -> 결과` 흐름으로 압축한다.
- 기존 Figma 원본 프레임은 보존하고, 새 프레임 `김준하 이력서 2p - 1`, `김준하 이력서 2p - 2`를 추가한다.

## 산출물

- Figma 템플릿 안의 2페이지 신규 프레임
- `output/pdf/kim-junha-junior-developer-resume.pdf`
- `public/kim-junha-junior-developer-resume.pdf`의 다운로드용 PDF
- `public/resume-2p.html`의 인쇄용 2페이지 요약본

## 검증

- Figma에서 두 신규 프레임의 텍스트 잘림·겹침을 스크린샷으로 확인한다.
- PDF를 PNG로 렌더링해 2페이지인지, 글자가 잘리지 않는지, 한글 폰트가 깨지지 않는지 확인한다.
